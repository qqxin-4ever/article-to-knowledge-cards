# make-knowledge-cards

把文章、笔记或本地 Markdown/TXT 文本，整理成 5–8 张可独立复习、忠于原文的 Markdown 知识卡片。

## 项目解决什么问题

长文章信息密集，普通摘要容易把多个概念揉在一起，逐段复述又抓不住重点；为了让卡片“看起来完整”而补充原文没有的内容，还会产生不可靠的学习材料。

make-knowledge-cards 是一个可移植的 Agent Skill。它先筛选原文的核心论点、机制、步骤、条件和限制，再把内容拆成单点知识卡片。信息不足时，它宁可少生成，也不通过重复、拆分或编造来凑数。

## 主要功能

- **输入**：用户直接粘贴的文本，或本地 `.md` / `.txt` 文件。
- **提炼**：保留真正重要的内容，合并语义重复，删除无关细节、装饰性叙述和结尾套话。
- **原子卡片**：一张卡片只讲一个知识点，包含标题、核心知识、简明解释，以及原文例子或自测问题。
- **忠于原文**：不添加原文没有的事实、数字、因果、定义或外部例子；保留作者、单团队数据、概率和条件范围。
- **诚实计数**：信息充足时生成 5–8 张；不足 5 个独立知识点时如实减少并说明；若连一张有意义的卡片都支撑不了，会要求补充材料。
- **语言与输出**：默认跟随原文语言，输出纯 Markdown；默认在对话中返回，不主动写文件。
- **暂不支持**：网页抓取、PDF 等文档转换、Anki 导出、图形界面、幻灯片和图片。

## 安装方法

该 Skill 是纯说明型 Agent Skill，不需要安装依赖或运行构建脚本。

```text
skills/make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

1. 保持或复制整个 `skills/make-knowledge-cards/` 目录；`agents/openai.yaml` 建议一并保留。
2. 如果客户端支持项目级 Skills，将目录放在项目根的 `skills/` 下，然后按客户端的方式重新加载或重新发现 Skills。
3. 如果客户端使用全局 Skills 目录，将整个 `make-knowledge-cards/` 文件夹复制到该客户端指定的目录。不同客户端的路径不同，以客户端文档为准。
4. 加载后，可以直接说“用 make-knowledge-cards 处理这篇文章”，也可以使用客户端支持的 `$make-knowledge-cards` 调用方式。

## 使用方法

### 粘贴文章

```text
使用 $make-knowledge-cards 把下面的文章转换成知识卡片：

<粘贴文章正文>
```

### 处理本地文件

```text
使用 $make-knowledge-cards 读取 ./notes/article.md，生成知识卡片。
```

支持 `.md` 和 `.txt` 文件。网页链接、PDF 等格式不会被自动抓取或解析；遇到这类输入时，Skill 会请求粘贴正文或提供本地 `.md` / `.txt` 文件。

### 输出与保存

- 默认在对话中输出 Markdown 卡片。
- 需要保存时，请明确给出目标路径，例如“保存为 `./cards/article.md`”。
- 除非明确要求，Skill 不会覆盖已有文件。
- 卡片数量、字段和语言会遵循 Skill 中定义的规则；原文语言为中文时，默认输出中文标签。

## 输入输出示例

下面用一则短消息演示“信息不足时不凑数”的分支。对于知识点足够的长文，Skill 会生成 5–8 张卡片。

**输入：**

```text
社区图书馆将从6月1日起，把周五、周六的闭馆时间从18:00延长至21:00。夜间只开放二楼自习室，少儿阅览区不开放。读者须在20:30前入馆。
```

**输出：**

```markdown
**来源：** 粘贴文本｜**卡片数：** 3

说明：原文只有 3 个独立且重要的信息点，不足 5 个，因此不额外补写卡片。

## 1. 延长开放只发生在周五、周六

**核心知识：** 社区图书馆从6月1日起，仅周五、周六延长开放至21:00，其他日期仍于18:00闭馆。

**简明解释：** 这则通知把延长开放限定在周五和周六两天，并给出了6月1日这个生效日期。其余日期的闭馆时间没有变化，仍是18:00。

**例子或自测：** 自测：周三晚上20:00图书馆还开放吗？参考答案：不开放，周三仍于18:00闭馆。

## 2. 夜间区域仅限二楼自习室

**核心知识：** 夜间开放只覆盖二楼自习室，少儿阅览区不开放。

**简明解释：** 延长开放不等于全馆开放。通知明确排除少儿阅览区，因此夜间能使用的区域只有二楼自习室。

**例子或自测：** 自测：夜间开放时可以去少儿阅览区吗？参考答案：不可以，夜间只开放二楼自习室。

## 3. 20:30前必须入馆

**核心知识：** 读者须在20:30前入馆。

**简明解释：** 20:30是通知规定的入馆截止时间，晚于这个时间到馆不符合入馆要求。

**例子或自测：** 自测：读者最晚应在几点前入馆？参考答案：20:30前。
```
